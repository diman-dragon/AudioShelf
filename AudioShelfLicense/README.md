# AudioShelf — выдача ключей разработчика

Инструмент вне проекта. Подробная инструкция записывается в начало `licenses.txt` при первом запуске.

Быстро: в проводнике перейти в папку лицензирования, двойной щелчок по `Выдать_ключ.bat`, ввести отпечаток телефона —
ключ покажется на экране и допишется в `licenses.txt` рядом. Нужен Node.js.

`secret.hex` — секрет: не публиковать и не пересылать; в приложении то же значение в `LicenseKey.java`.
Ключи подходят к AudioShelf 0.9.3 и новее.
