# Changelog

## 0.3.2
- **Книги вместо файлов.** Папка с несколькими файлами — одна книга: файлы становятся главами по порядку имён (с учётом чисел: «2» перед «10»). Файлы прямо в выбранной папке остаются поодиночке.
- Плеер играет главы подряд: кнопки предыдущая / следующая глава, список «Главы», подпись «Глава N из M». Прогресс запоминается по книге (глава и место).
- Теги, скрытие и удаление работают на книгу целиком; «Удалить с диска» у книги-папки удаляет папку.
- В настройках кнопка **«Убрать»**: папка перестаёт отслеживаться, библиотека очищается, плеер останавливается, системе возвращается доступ. Файлы, теги и прогресс остаются.
- **Шторка плеера** не появлялась: сервис не подключал медиасессию, поэтому Media3 не создавал уведомление. Исправлено.
- Папка просматривается **только при выборе и по кнопке «Обновить»**; на старте — сохранённый список. Добавление, удаление, переименование и скрытие меняют список без обхода.
- Обход в 4 потока (каждая подпапка — отдельная задача), приложением можно пользоваться во время сканирования. Остановка сохраняет прежний список.
- Большой список рисуется порциями.
- Атомарность: крупные файлы разделены (CSS, окно «Изменить», состояние и обход библиотеки, Java-плагины).

## 0.3.1
- Настройки показывают путь выбранной папки («Память устройства › Audiobooks › Books») и сколько файлов в библиотеке.
- Библиотека теперь собирается из папки **и всех её подпапок**.
- Сканирование идёт в фоне с прогрессом (найдено файлов, пройдено папок) и кнопкой «Остановить».
- Кнопка «Обновить» (повторное сканирование) в библиотеке; сканирование также при запуске и возврате в приложение.
- Все сообщения — в своих окнах; системных alert/confirm/prompt в приложении не осталось.

## 0.3.0
- Окно «Изменить»: тип (книга / альбом), название, автор или исполнитель, чтец, год и имя файла. У каждого поля подсказка, где оно показывается. Теги хранятся в приложении, сам файл не меняется.
- Теги видны в библиотеке (заголовок, автор, сведения), в плеере и в шторке.
- Удаление: «Убрать из библиотеки» (файл остаётся на диске, возврат — в настройках) или «Удалить с диска».
- Обложка по умолчанию — крупное цветное эмодзи на 3/4 поля: книга не открывалась — закрытая (корешок слева), начата — открытая, дослушана — закрытая корешком вправо; альбом — диск.
- Свои окна вместо системных prompt/confirm; системная «Назад» их закрывает.

## 0.2.1
- Шторка (уведомление плеера): название, обложка файла, иконка приложения, кнопка ✕ — останавливает воспроизведение и убирает шторку.
- Смахивание приложения из списка недавних останавливает плеер и убирает шторку.
- Связь шторки и приложения: пауза/пуск из шторки, с наушников и по системным кнопкам сразу отражается в приложении; позиция запоминается при закрытии.
- Шаги перемотки системных кнопок: −15 / +30 секунд.

## 0.2.0
- Встроенный плеер на Media3 ExoPlayer: пуск/пауза, перемотка −15 / +30 с, ползунок, скорость 0.75–2×, обложка.
- Фоновое воспроизведение, уведомление и управление с экрана блокировки (MediaSession).
- Позиция запоминается для каждого файла; последний файл восстанавливается.
- Нажатие на файл в библиотеке запускает плеер; «Открыть в другом приложении» — в меню файла.

## 0.1.2
- Библиотека: список аудиофайлов выбранной папки; переключатель «строки / карточки» (пиктограммы), «Добавить», меню файла (открыть, переименовать, удалить), обложки из тегов.
- Нативные плагины Android (Folder, FileOps, Cover) через Storage Access Framework; в браузере — заглушка.
- Настройки: папка с аудио, тема, язык; новое оформление.
- Нижние вкладки с эмодзи в новом стиле.
- Темы: светлая и тёмная (по умолчанию как в системе).
