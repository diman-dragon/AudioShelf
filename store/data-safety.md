# Data safety — ответы для формы в Play Console

Раздел: **Политика и программы → Безопасность данных** (App content → Data safety).

| Вопрос | Ответ |
|---|---|
| Собирает ли приложение или передаёт обязательные типы данных пользователя? | **Нет** |
| Данные собираются? | **Нет** — ни один тип данных не отмечать |
| Данные передаются третьим лицам? | **Нет** |
| Все данные шифруются при передаче? | Не применимо (данные не передаются). Если форма требует ответ — «Да»/N/A |
| Можно ли запросить удаление данных? | Не применимо: данных на серверах нет. Удаление — удалить приложение |
| Ссылка на политику конфиденциальности | `https://<ваш-логин>.github.io/<репозиторий>/` (страница `docs/index.html`) |

## Почему «нет»

- В коде нет собственных сетевых запросов, аналитики, рекламы, SDK третьих лиц, аккаунтов. Единственная внешняя библиотека — Google Play Billing: платежи и платёжные данные обрабатывает Google, разработчик их не получает, поэтому «История покупок» и «Платёжная информация» не отмечаются.
- Библиотека, закладки, позиции, настройки звука хранятся только на устройстве (localStorage WebView).
- Доступ к папкам — через системный выбор папки (SAF), без разрешений на хранилище.
- Разрешение `INTERNET` осталось в манифесте (значение по умолчанию Capacitor); собственных запросов приложение не делает.
  (Если захотите убрать: удалить строку в `AndroidManifest.xml`, проверить сборку и работу WebView на устройстве.)
- Резервное копирование Android (Auto Backup) может копировать данные приложения в аккаунт Google пользователя —
  это системная функция, не передача разработчику.

## Другие декларации

- **Реклама:** нет.
- **Встроенные покупки:** да (Премиум — разовая покупка; три необязательных «чаевых»). В карточке отобразится «Есть встроенные покупки». Подписок нет.
- **Доступ к приложению:** вход не нужен, всё доступно без ограничений.
- **Целевая аудитория:** 18+ (не для детей) — так проще, не включается программа Families.
- **Категория:** «Музыка и аудио» (запасной вариант — «Книги и справочники»).
- **Рейтинг контента (IARC):** насилия, секса, азартных игр, покупок, общения между пользователями — нет → ожидаемый рейтинг «3+/Everyone».
- **Новостное, COVID, финансовое, здоровье, государственное:** нет.
- **Foreground service `mediaPlayback`:** используется для воспроизведения при выключенном экране и шторки управления.
  В форме декларации: «Воспроизведение аудиокниг и музыки в фоне; пользователь запускает и останавливает вручную».
  Нужно короткое видео (30–60 с): запуск книги → экран выключается → звук идёт → шторка уведомления → пауза.
- **Разрешения:** `POST_NOTIFICATIONS` — шторка управления плеером; `WAKE_LOCK` — воспроизведение при погашенном экране.
